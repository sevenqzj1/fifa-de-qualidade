# Arena Futebol

Protótipo web de futebol arcade, com identidade própria, feito em HTML, CSS e JavaScript.

## Estado atual

- [x] Campo 2D responsivo e placar.
- [x] Partida contra IA com movimentação, bola, chutes, goleiros, cronômetro e resultado.
- [x] Controles de teclado e controles básicos para celular.
- [x] Modo de treino livre.
- [ ] X1 online entre dois jogadores reais — requer backend/sincronização e testes com dois clientes.
- [ ] X2 online — etapa posterior ao X1 online.

## Executar localmente

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências.

## Controles

- WASD ou setas: mover.
- Espaço: chutar quando estiver perto da bola.
- Shift: correr.
- P ou Esc: pausar.

> O X1 contra IA é o primeiro protótipo. Multiplayer online ainda não está implementado e não deve ser considerado funcional até que seja conectado a um servidor e validado em duas sessões distintas.
